

## Связка Месяц→День (задачи) и положение планет в Астро дня

### Часть 1. Месяц → задачи Дня

**Логика:** одна строка текста в ячейке Месяца = одна задача в Дне на эту же дату. Заметки месяца перестают быть свободным текстом — становятся списком задач (без чекбоксов прямо в Месяце, чтобы не загромождать сетку), а в Дне это полноценные задачи с чекбоксами.

**Источник правды:** таблица `tasks` (а не `notes`). Таблица `notes` остаётся для свободных мыслей в блоке «Заметки» Дня.

**`src/routes/app.month.overview.tsx`:**
- Загружать из `tasks` (`is_done`, `title`, `sort_order`, `date`) для диапазона видимого месяца, а не из `notes`.
- Текстовое поле ячейки превращается в textarea, где **каждая строка = задача**. При сохранении (`onBlur`):
  - Парсим текущее содержимое на строки (trim, фильтр пустых).
  - Сравниваем с уже существующими задачами этого дня по позиции/тексту.
  - Создаём новые, обновляем изменённые `title`, удаляем убранные. Завершённые задачи (`is_done=true`) показываем зачёркнуто-серым префиксом или пропускаем — оставляем только незавершённые в textarea, чтобы не путать пользователя при редактировании.
- Перед каждой строкой (опционально, мелким) — точка/чекмарк для уже выполненных, чтобы было видно прогресс. Чекбоксы не делаем — в Месяце редактируется только текст.

**`src/routes/app.day.tsx`:**
- Уже читает `tasks` по дате — изменений почти нет. Убираем фильтр `is("time_slot", null)` либо оставляем (зависит — задачи из Месяца идут без time_slot, и сейчас они корректно подгрузятся). Оставляем как есть.
- Любое редактирование/удаление/чекбокс в Дне сразу отражается на следующей загрузке Месяца.

**`src/components/auto-grow-note.tsx`:** остаётся как переиспользуемый textarea авто-роста, просто теперь в Месяце он привязан к спискам задач, а не к notes.

### Часть 2. Астро дня — текущее положение планет

**Логика:** на выбранную дату для каждой планеты из `{moon, sun, mercury, venus, mars, jupiter, saturn, rahu, ketu}` находим **последний ingress** (`event_type = 'ingress'`) с `date <= выбранная дата` — это и есть знак, в котором планета находится сегодня.

**`src/routes/app.day.tsx`:**
- Вместо `eq("date", date)` для астро-блока делать **два запроса**:
  1. События **точно на этот день** (новолуния/полнолуния, ретрограды, переходы знаков сегодня) — как сейчас, для блока «Активные транзиты сегодня».
  2. **Последний ingress на каждую планету** до и включая эту дату — для нового блока «Положение планет». Один SQL-запрос: `select distinct on (planet) planet, sign, date from astro_events where event_type='ingress' and date <= :date order by planet, date desc`.
- В блоке «Астро дня» добавить секцию **«Положение планет»**: иконка/название планеты на русском + знак, в котором она сейчас. Например: «☽ Луна — Стрелец, ☉ Солнце — Овен, ☿ Меркурий — Рыбы…».
- Текущая секция «Активные транзиты» остаётся ниже и показывает только события, выпавшие непосредственно на этот день (если есть).
- Цвет дня (`dominantColor`) считаем по событиям именно этого дня, как сейчас.

**Технически:**
- Supabase JS не поддерживает `distinct on` напрямую. Решения:
  - Запросить все ingress'ы за последние ~45 дней до выбранной даты (этого хватит для всех планет, кроме Юпитера/Сатурна/Раху/Кету — для них нужен более широкий диапазон), затем в JS сгруппировать по planet и взять последнюю дату. Безопасно: запросить за 400 дней назад — покрывает Юпитер. Получится ~50–80 строк.
  - Альтернатива: создать SQL view или RPC `current_planetary_positions(in_date date)`. Но это лишний шаг, JS-вариант проще и работает без миграции.
- Создам helper в `src/lib/astro.ts`: `currentPositions(events: AstroEvent[], onDate: string): Record<planet, sign>` + словари `PLANET_RU`, `PLANET_GLYPH`, `SIGN_RU`.

### Что НЕ меняется

- Таблица `notes` остаётся — для свободного текста в блоке «Заметки» Дня и в полосе заметок Недели.
- Часовые задачи Недели (`tasks` с `time_slot`) работают как раньше.
- Никаких миграций БД — всё на существующих таблицах.

### Поведение после правок

- В Месяце пишете «купить молоко\nпозвонить маме» в ячейке 22 апреля → переходите на День 22 апреля → две задачи с чекбоксами уже там. Ставите галочку «купить молоко» → возвращаетесь в Месяц → строка показана выполненной (или скрыта).
- В Дне 22 апреля видите блок «Положение планет»: Луна в Овне, Солнце в Овне, Меркурий в Рыбах, Венера в Тельце… (на любую дату, даже без событий именно в этот день).
