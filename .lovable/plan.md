

## Заметки во весь размер ячейки на вкладке Месяц

### Проблема

Сейчас в ячейке месяца `Textarea` имеет фиксированные `rows={2}` и `min-h-[44px]` с `resize-none`. Длинный текст обрезается и появляется внутренняя прокрутка. Нужно: текст виден целиком, поле растёт по высоте под содержимое, занимает всё свободное место в ячейке.

### План правок (1 файл)

**`src/routes/app.month.overview.tsx`**

1. **Убрать фиксированную высоту и прокрутку у textarea:**
   - Убрать `rows={2}` и `min-h-[44px]`.
   - Добавить `overflow-hidden` (чтобы скроллбар не появлялся).
   - Класс высоты: `h-full flex-1` — поле растягивается на всё свободное место в ячейке (ячейка уже `flex flex-col`).

2. **Авто-рост высоты под содержимое:**
   - Добавить `ref` на textarea и эффект, который при изменении `value` выставляет `el.style.height = 'auto'` затем `el.style.height = el.scrollHeight + 'px'`. Это стандартный паттерн авто-grow.
   - Так текст всегда виден целиком, без скролла.

3. **Дать ячейке расти под содержимое:**
   - Заменить фиксированный `min-h-[130px]` на `min-h-[140px]` как стартовое значение, но убрать любые `overflow-hidden` / `max-h` ограничения с самой ячейки, чтобы она вытягивалась вниз вместе с заметкой.
   - Сетка `grid grid-cols-7` сама подгонит соседние ячейки в строке под высоту самой высокой — это нативное поведение CSS Grid, специальной правки не требует.

4. **Шрифт и отступы оставить как есть** (`text-xs leading-tight px-1.5 py-1`) — компактно, чтобы влезало больше текста.

### Поведение после правки

- Короткая заметка («встреча 14:00») — ячейка остаётся компактной, ~140px.
- Длинная заметка на 5–10 строк — ячейка и весь ряд недели плавно растягиваются вниз, текст показан полностью без скроллбара.
- На других вкладках (День, Неделя) ничего не меняется — данные те же.

### Технические детали

- `useRef<HTMLTextAreaElement>` + `useEffect([value])` для авто-grow.
- При первом рендере (загрузка заметок из БД) эффект тоже сработает и подгонит высоту существующих заметок.
- Никаких изменений в БД, типах, других роутах.
